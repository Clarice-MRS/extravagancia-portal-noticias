# EXTRAVÂNCIA - PORTAL DE NOTÍCIAS 

Projeto desenvolvido para a matéria de WEB com o objetivo de criar um portal de notícias, envolvendo recursos interativos como relógio, tema claro/escuro, filtro, busca, carregar mais e newsletter com mensagem de confirmação.

Permite visuzalizar as notícias, assinar a newsletter, filtrar as notícias por categoria e realizar uma busca.

Não é possível acessar cada notícia indivualmente para ler a matéria completa.

## Funcionalidades

- Busca de notícias em tempo real
- Filtro de notícias por categoria
- Relógio com data e hora atualizadas em tempo real
- Alternância entre modo claro e escuro
- Formulário de inscrição na newsletter

## Requisitos entregues

**Obrigatórios**

- [x] Utilizar as tags semânticas `header`, `nav`, `main`, `section`, `article`, `aside` e `footer`.
- [x] Apresentar no mínimo 8 notícias.
- [x] Exibir título, categoria, autor/data e imagem com `alt` nas notícias.
- [x] Utilizar no mínimo 2 fontes definidas por variáveis CSS.
- [x] Desenvolver layout responsivo utilizando Flexbox e/ou Grid.
- [x] Implementar estados visíveis de `hover` e `focus` nos elementos interativos.
- [x] Implementar pelo menos 2 recursos interativos com JavaScript.

**Bônus**

- [x] Persistir o tema escolhido utilizando `localStorage`.
- [x] Implementar mais de 2 recursos interativos em JavaScript.
- [x] Utilizar animações e transições sutis.
